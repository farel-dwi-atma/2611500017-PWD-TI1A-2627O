# pertemuan-01
Bukti Belajar P1

1. **Konsep Dasar Pemrograman Web**
   Pembuatan aplikasi web yang berjalan di browser, terbagi menjadi dua sisi eksekusi: *client-side* (pengguna) dan *server-side* (peladen). <br>

2. **Arsitektur Klien-Peladen (Client-Server)**
   * **Client:** Aplikasi/browser yang meminta data/layanan.
   * **Server:** Komputer penyedia layanan yang memproses permintaan dan mengirimkan balasan. <br>

3. **HTTP Request dan Response**
   * **HTTP Request:** Pesan dari *client* ke *server* (`GET` untuk mengambil data, `POST` untuk mengirim data).
   * **HTTP Response:** Balasan dari *server* ke *client* berisi status (`200 OK`, `404 Not Found`) dan data. <br>

4. **HTML, CSS, JavaScript, PHP, MySQL**
   * **HTML:** Struktur dan konten web.
   * **CSS:** Tampilan, gaya, dan tata letak.
   * **JavaScript:** Interaktivitas di sisi *client*.
   * **PHP:** Logika pemrosesan di sisi *server*.
   * **MySQL:** Penyimpanan dan pengelolaan basis data. <br>

5. **Hubungan Antarteknologi**
   User (Browser) $\rightarrow$ **HTTP Request** $\rightarrow$ **PHP** (Server) $\rightarrow$ **MySQL** (Database) $\rightarrow$ **HTTP Response** (HTML/CSS/JS) $\rightarrow$ Tampilan akhir di Browser. <br>
